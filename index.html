Introduction

This Privacy Policy explains how Moogie (referred to as “the Bot”, “we”, or “us”) accesses, processes, and stores information obtained through Discord.

Moogie is a self-hosted Discord bot application operated by a sole owner. It runs instances of the open-source NadekoBot, together with their configured modules and extensions.

Moogie is independently operated and is not affiliated with, endorsed by, or operated by Discord, or NadekoBot.

The Bot operates within the Discord servers in which it has been installed and uses Discord data only to provide the moderation, administration, community, utility, and other features configured for those servers.

1. Information We Access and Process

1.1 User and Member Information

Moogie receives Discord member information as necessary for its operation, including information such as:

  • Discord User ID;
  • username and display name;
  • avatar and other Discord profile information made available to the Bot;
  • server membership information;
  • roles and permissions; and
  • member-related events.

This information is processed to allow the Bot to perform member management, moderation, role management, welcome functionality, permissions, and other server-management functions.

Moogie does not maintain an off-platform database of general Discord member profiles, and this information is not retained independently for profiling or tracking purposes.

1.2 Message Content

Moogie requires access to message content to provide message-based functionality offered.

Message content may be processed in real time for purposes including:

  • processing traditional bot commands;
  • custom commands and configured responses;
  • determining eligibility for XP or participation rewards;
  • preventing repeated or spam messages from improperly generating XP;
  • message filtering and other configured bot functionality;
  • automated responses;
  • link handling;
  • tickets and other message-based features; and
  • other functionality configured by server administrators.

Moogie does not maintain a general-purpose archive or database of messages sent in the server.

Message content is normally processed only as necessary for the relevant feature to operate.

1.3 User- or Administrator-Submitted Content

Some Bot features intentionally allow users or server administrators to submit information for the purpose of providing a particular feature.

Examples include:

  • custom command trigger phrases and responses;
  • reminders;
  • AFK messages;
  • welcome and leave messages; and
  • other configurable Bot responses or content.

Where such information is intentionally configured for a Bot feature, it may be stored so that the feature can continue to operate.

This stored information exists only for the configured feature and may be removed by server administrators by disabling or unsetting the relevant configuration.

1.4 Presence and Activity Information

Moogie may receive Discord presence and activity information where required by the Bot's functionality, including information relating to online status and activities such as streaming.

Presence and activity information is processed to provide relevant Bot functionality.

Moogie does not maintain an off-platform database of users' presence or activity information.

2. Message Processing and XP

Moogie provides an XP system that can award points for participation in a Discord guild.

For this functionality, message content may be inspected in real time to determine whether a message qualifies for an XP award. This can include checking requirements such as minimum message length and preventing messages sent in rapid succession from being used to artificially accumulate XP.

The content of the messages is not stored as a general message history for this purpose.

The same principle applies to Moogie's custom command functionality. Server administrators may configure trigger phrases and responses, allowing the Bot to provide server-specific FAQ responses or community utility shortcuts when users naturally type configured trigger words.

The Bot needs to inspect message content in order to identify these configured triggers, but it does not need to store the general messages in which those triggers occur.

Custom commands and similar features are configured by server administrators and are not a substitute for, or implementation of, Discord's AutoMod functionality.

3. How We Store Your Data

Moogie does not maintain an off-platform database of general Discord message history, member profiles, or presence/activity history.

Information intentionally configured for persistent Bot features may be stored in the Bot's database where required for those features to function. Examples include custom command configurations, reminders, AFK messages, and welcome/leave message templates.

Such information is stored only for the purpose for which it was configured.

Where a Bot feature provides server administrators with the ability to unset or remove its stored configuration, administrators may do so without needing to contact the Bot administrator.

The Bot's infrastructure and associated databases are operated by the Bot administrator. Access to the infrastructure is restricted to authorised individuals responsible for operating and maintaining Moogie.

4. How We Use Your Data

Information accessed or processed by Moogie is used only for purposes connected with operating the Bot and providing configured Discord server functionality, including:

  1. Bot commands — processing commands and providing the functions offered by Red Discord Bot and NadekoBot.
  2. Community features — providing custom commands, automated responses, XP, games, reminders, and other community functionality.
  3. Moderation and administration — providing configured moderation, role, permission, filtering, and server-management functionality.
  4. Member management — responding to member events and providing role, welcome, and other member-related functionality.
  5. Server configuration — retaining information deliberately configured by server administrators where necessary for a particular Bot feature.

Moogie does not use Discord data for advertising, sale, unrelated commercial profiling, or training artificial intelligence or machine-learning models.

5. Data Sharing and Disclosure

We do not sell, rent, or trade information obtained through Discord.

Information may be accessible to:

  1. Authorised server staff, where a Bot feature makes relevant configuration or information available to moderators or administrators; and
  2. The Bot administrator, for the purpose of operating, maintaining, securing, and troubleshooting Moogie.

We do not otherwise provide Discord user data to unrelated third parties.

Information may be disclosed where reasonably necessary to comply with applicable law, valid legal process, or a legitimate request from Discord relating to the operation or safety of the Discord platform.

6. Data Retention and Removal

Moogie does not retain a general history of messages sent in Discord.

Information intentionally stored for configured Bot features is retained only for as long as it is required for the relevant feature.

Server administrators can remove stored configuration for applicable features by unsetting or disabling those features. This allows information such as configured custom commands, responses, reminders, AFK messages, and greeting templates to be removed without requiring a user to contact the Bot administrator.

Where a user has an appropriate reason to request removal of information that cannot be removed through the relevant Bot configuration, they may contact the Bot administrator using the contact information below.

Information independently retained by Discord or by other Discord users is outside the control of Moogie and is not removed by changes to Moogie's database.

7. Contacting the Bot Administrator

The Bot administrator's Discord username is publicly provided in Moogie's Bot profile.

A Discord server is also provided in the Bot's profile so that users can contact the administrator directly.

The Bot administrator is additionally present in Discord servers in which Moogie is installed and which meet the applicable server-size threshold, providing another means for users to make contact.

8. Discord and Third-Party Software

Moogie operates through the Discord platform and necessarily interacts with Discord's systems and APIs.

Discord independently processes information in accordance with its own policies and terms. Moogie does not control Discord's collection, storage, or processing of information on Discord's platform.

Moogie uses the open-source NadekoBot projects as software components. These projects are used as part of this independently operated, self-hosted Bot instance and are not responsible for the administration or operation of this instance.

9. Children's Privacy

Moogie does not knowingly use Discord information for advertising, profiling, or other commercial purposes directed at children.

Users must comply with Discord's applicable age requirements and terms when using Discord.
